# Microsoft Azure Documentation

Welcome to the open-source [Microsoft Azure documentation](https://learn.microsoft.com/azure/?product=popular).

This repository contains the source content for Microsoft Azure documentation. If you'd like to contribute, this README provides an overview of the prerequisites and resources you need to get started.

## Getting Started

Contributing to open source is more than making documentation updates. You can also help by reporting issues, suggesting improvements, or reviewing existing content.

Before making a contribution, read our [Contributing guide](CONTRIBUTING.md) for detailed information about the contribution process.

### Prerequisites

Before contributing to the Azure documentation, you'll need a few basic tools and accounts.

#### GitHub Account

A [GitHub account](https://github.com/) is required to contribute to this repository.

If you don't have a GitHub account, follow the [GitHub account setup guide](https://learn.microsoft.com/contribute/get-started-setup-github) for step-by-step instructions.

#### Required Tools

You'll need to install the tools used to create and validate Microsoft Learn content.

Follow the [Install content authoring tools](https://learn.microsoft.com/contribute/get-started-setup-tools) guide to set up your development environment.

### Need Help?

If you're new to contributing, start with the [Contributing guide](CONTRIBUTING.md). It explains how to:

* Set up your development environment
* Create and edit documentation
* Build and validate content
* Submit changes through GitHub
* Report issues and suggest improvements
