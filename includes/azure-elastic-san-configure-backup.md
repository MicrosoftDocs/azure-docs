## Configure operational backup for Azure Elastic SAN volume by using the Azure portal

To configure operational backup for an Azure Elastic SAN volume, follow these steps:

1. In the [Azure portal](https://portal.azure.com/), go to **Resiliency**, and select **+ Configure protection**.
1. On the **Configure protection** pane, select **Resource managed by** as **Azure**, **Datasource type** as **Elastic SAN volumes**, **Solution** as **Azure Backup**, and select **Continue**.

   :::image type="content" source="../articles/backup/media/azure-elastic-storage-area-network-backup-configure/start-protection-configuration.png" alt-text="Screenshot that shows how to start configuring backup." lightbox="../articles/backup/media/azure-elastic-storage-area-network-backup-configure/start-protection-configuration.png":::

1. On the **Configure Backup** pane, on the **Basics** tab, ensure that the **Datasource type** is selected as **Elastic SAN volumes**.
1. Under **Vault**, select **Select vault** to choose the Backup vault.

   > [!NOTE]
   > A Backup vault uses a system-assigned managed identity to create and manage snapshots.

1. On the **Backup policy** tab, under **Backup policy**, select the policy to use for data retention, and select **Next**.

   If you want to create a new backup policy, select **Create new**. To learn more, see [Quickstart: Create an operational backup policy for Azure Elastic SAN volume](../articles/backup/azure-elastic-san-backup-quickstart.md).

1. On the **Datasources** tab, select **Add** to choose the **Elastic SAN instance** for backup.

   :::image type="content" source="../articles/backup/media/azure-elastic-storage-area-network-backup-configure/add-resource-for-backup.png" alt-text="Screenshot that shows how to add resources for backup." lightbox="../articles/backup/media/azure-elastic-storage-area-network-backup-configure/add-resource-for-backup.png":::

1. On the **Select resources to backup** pane, select an **Elastic SAN instance** from the dropdown list, and select **Add**.

   The list shows only instances that belong to the same subscription and region as the vault.

   :::image type="content" source="../articles/backup/media/azure-elastic-storage-area-network-backup-configure/specify-backup-instance-name.png" alt-text="Screenshot that shows how to select an instance for backup." lightbox="../articles/backup/media/azure-elastic-storage-area-network-backup-configure/specify-backup-instance-name.png":::

1. On the **Add backup instance** pane, filter by **Volume group**, select a volume from the list, and select **Add**.

   > [!NOTE]
   > - You can select multiple volumes in a single backup request. Azure Backup creates a separate backup instance for each selected Elastic SAN volume and associated backup policy. A backup instance represents the pairing of an Elastic SAN volume and a backup policy. You can use the autogenerated backup instance name or provide a custom name.
   > - By default, Azure Backup stores restore point snapshots in the same resource group as the Elastic SAN volume. You can select a different resource group to store the snapshots.

1. After you add the backup instances, backup readiness validation starts on the **Configure Backup** pane, under the **Datasources** tab.

   Validation errors appear if the selected Backup vault's managed identity doesn't have the **Elastic SAN Snapshot Exporter** and **Disk Snapshot Contributor** roles assigned.

1. To assign the required roles, on the **Configure Backup** pane, on the **Datasources** tab, select **Assign missing roles**.

   > [!NOTE]
   > If you don't have **Role-Based Access Control Administrator** permissions, the **Assign missing roles** option is disabled.

1. On the **Grant missing permissions** pane, select the scope at which you need to grant the access permissions, and select **Next**.
1. When the role assignment is complete, on the **Configure Backup** pane, on the **Datasources** tab, select **Revalidate**.
1. On the **Review + configure** tab, review the configuration details, and then select **Configure Backup** to finish the backup configuration.

You can [track the progress of the backup configuration](../articles/backup/azure-elastic-san-backup-manage.md#view-the-elastic-san-volume-backup-and-restore-jobs-by-using-the-azure-portal) under **Backup instances**.
