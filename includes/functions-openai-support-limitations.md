> [!WARNING]
> The Azure OpenAI extension for Azure Functions retires on April 20, 2027. Preview extension bundle version 4.60.0 and later don't include the extension.
>
> Migrate to the OpenAI, Microsoft Foundry, or Azure AI Search SDKs directly, depending on your scenario. Existing apps can use preview extension bundle versions earlier than 4.60.0 by setting the version range to `[4.*, 4.60.0)` in `host.json`. Pinning an older bundle doesn't extend support beyond April 20, 2027.
