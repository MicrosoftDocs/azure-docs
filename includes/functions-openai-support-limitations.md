> [!WARNING]
> The Azure OpenAI extension for Azure Functions retires on April 20, 2027. Preview extension bundle version 4.60.0 and later don't include the extension.
>
> Migrate to the OpenAI, Microsoft Foundry, or Azure AI Search SDKs directly, depending on your scenario. Existing apps can use preview extension bundle versions earlier than 4.60.0 by setting the version range to `[4.*, 4.60.0)` in `host.json`. .NET apps can continue using the corresponding Azure OpenAI extension NuGet packages directly. Neither pinning an older bundle nor continuing to use the NuGet packages extends support beyond April 20, 2027.
