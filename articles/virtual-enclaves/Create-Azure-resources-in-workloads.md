# Tutorial: Create Azure resources in a workload on Azure Virtual Enclaves

An Azure resource is a manageable item that is available through Azure. Virtual machines, storage accounts, web apps, and databases are examples of resources.

In this tutorial, part five of eight, you create Azure resources in workloads. You learn how to:

- ✅ Provision Azure resources into workloads
- ✅ View your Azure resources in Azure Portal
- ✅ View your workloads in Azure Portal
