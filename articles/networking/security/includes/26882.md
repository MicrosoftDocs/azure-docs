Azure Application Gateway Web Application Firewall (WAF) provides bot protection through the Microsoft Bot Manager rule set, which classifies automated traffic as known good, known bad, or unknown based on behavioral patterns, bot signatures, and IP reputation. Without the rule set enabled, credential stuffing, content scraping, inventory hoarding, and application-layer denial of service traffic blends in with legitimate requests and consumes backend capacity. Attacks of this kind commonly originate from distributed botnets that rotate IP addresses to evade rate limiting, which is why signature-based classification is needed rather than throttling alone.
