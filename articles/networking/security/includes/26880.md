Azure Front Door Web Application Firewall (WAF) inspects HTTP POST, PUT, and PATCH request bodies for SQL injection, cross-site scripting, and command injection payloads at the edge, before traffic is forwarded to your origins. With request body inspection turned off, only headers and the URI are evaluated at the edge, so payloads hidden in form posts, API calls, and file uploads are forwarded to origins unexamined. Managed rule sets, including the Open Worldwide Application Security Project (OWASP) Core Rule Set and Microsoft's threat intelligence-based rules, can't act on content they never see.
