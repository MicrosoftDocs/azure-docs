Azure Application Gateway Web Application Firewall (WAF) inspects HTTP POST, PUT, and PATCH request bodies for SQL injection, cross-site scripting, and command injection payloads before traffic reaches your regional backend pool. With request body inspection turned off, the WAF evaluates only request headers and the URI, so payloads hidden in form posts, API calls, and file uploads reach backend servers unexamined. Managed rule sets, including the Open Worldwide Application Security Project (OWASP) Core Rule Set and the Microsoft Bot Manager rule set, can't act on content they never see.
