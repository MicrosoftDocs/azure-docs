> [!IMPORTANT]
> Perimeter links are currently in preview. They're available across all network security perimeter supported Azure public and Azure Government cloud regions.
> During this preview, the following PaaS services support cross-perimeter connectivity:
>  - Azure SQL Database
>  - Azure Storage
>  - Azure Cosmos DB
>  - Azure Key Vault (AKV)
>  - Azure Monitoring
>  - Azure Service Bus
>
> You can access the feature through the Azure portal, CLI, PowerShell, and API.
