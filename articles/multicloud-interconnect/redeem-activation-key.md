# Redeem an Azure Multicloud Interconnect Preview activation key

This article shows you how to redeem an activation key that your cloud service provider generated, which completes an Azure Multicloud Interconnect Preview connection from the Azure side.

Azure Multicloud Interconnect supports two onboarding paths. Use this article when the request starts with your cloud service provider and you complete the Azure side. If you want to start from Azure instead and generate the key yourself, see [Create an Azure Multicloud Interconnect Preview resource](create-interconnect.md).

> [!IMPORTANT]
> Azure Multicloud Interconnect is currently in PREVIEW.
> See the [Supplemental Terms of Use for Microsoft Azure Previews](https://azure.microsoft.com/support/legal/preview-supplemental-terms/) for legal terms that apply to Azure features that are in beta, preview, or otherwise not yet released into general availability.

## Prerequisites

- An Azure account with an active subscription
- An activation key generated by your cloud service provider
- An account with a supported cloud service provider. For the providers and regions supported during preview, see [Availability and limits](availability-limits.md).

## Redeem the activation key

Redeem a provider-generated activation key when you create the interconnect circuit. Don't use a separate page.

1. Sign in to the [Azure portal](https://portal.azure.com).
1. Search for and select **Hybrid connectivity**.
1. In the left menu, expand **Azure Multicloud Interconnect**, and then select **Set up Azure Multicloud Interconnect**.
1. Select **Create Multicloud Interconnect Circuit**.
1. On the **Configuration** tab, under **Project details**, select your subscription and resource group. To create a new resource group, select **Create new**.
1. Under **Port details**, for **Port type**, select **Azure Multicloud Interconnect**.
1. Enter a name for the circuit.
1. Select the **Multicloud provider**, **Region**, and **Bandwidth** that match the connection your provider requested. To view the provider-to-region mappings, select **View region mapping**.
1. Under **Activation key**, select **Redeem Activation Key**, and then provide the key that your cloud service provider supplied.
1. Enter the **Account ID** for your account with the cloud service provider.
1. Select **Review + create**, review the configuration, and then select **Create**.

The provider validates that the key details match the account and the requested connection. If validation succeeds, Azure and the provider configure the underlying connectivity and the resource moves toward a provisioned state.

## Connect the interconnect to a virtual network

To reach your Azure workloads over the interconnect, connect it to a virtual network.

1. Create an ExpressRoute virtual network gateway. Traffic entering Azure over the interconnect uses this gateway.
1. Create an ExpressRoute connection that links the gateway to the interconnect.
1. Verify connection health, and then validate that your workloads can communicate across both clouds.

## Troubleshoot a failed validation

If validation fails, provisioning doesn't start. Confirm that the cloud service provider, Azure region, bandwidth, and provider account details match the original request. Correct any mismatch, and then redeem the key again.
