# Azure CycleCloud version 8.9.2

This release contains many security-related fixes. It also introduces several new features and resolves existing problems.

## New features
- The cluster page now displays return proxy connection status.
- Azure CycleCloud supports the Azure Bleu provider.

## Resolved Issues
- CycleCloud CLI couldn't be installed in a uv managed Python environment.
- CycleCloud CLI `account create` interactive wizard was broken.
- The **Edit** button in the Nodes table didn't open the **Edit** dialog.
- When you edited a cluster in the UI, the process sometimes removed cluster-init specs.
- Some node problems didn't properly display the node name or description.
- The cluster edit UI was very slow with many node arrays.
- When a built-in authentication session expired, the UI didn't prompt the user to sign in again.
- Clusters which were upgraded from 8.8.x to 8.9.x did not mount Lustre properly.
- CycleCloud LSF defaulted to using a Centos7 image, which is past its end of life date.
- CycleCloud LSF didn't install the ed package required on Rocky Linux.
- lsfd was inherited with jetpackd due to being in the same cgroup.
- The monitoring dashboard queries filtered on partial matches instead of exact matches.
- The *Basic* SKU for public IP was deprecated.
- Windows nodes failed to install jetpack if outbound internet was restricted.
- Resolved CVEs: CVE-2026-65806, CVE-2026-70340.
