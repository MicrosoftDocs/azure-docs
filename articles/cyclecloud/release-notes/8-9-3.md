# Azure CycleCloud version 8.9.3 

This release contains many security-related fixes. 

## Resolved problems

*   Azure CycleCloud automatically removed extensions that users or external automation (such as Azure Policy) added to Virtual Machine Scale Sets when the corresponding node array was resized.
*   The Full Name field for CycleCloud users wasn't automatically populated when using Entra for authentication.  
*   Resolved CVEs: [CVE-2024-21503](https://nvd.nist.gov/vuln/detail/CVE-2024-21503), [CVE-2025-66418](https://nvd.nist.gov/vuln/detail/CVE-2025-66418), [CVE-2025-66471](https://nvd.nist.gov/vuln/detail/CVE-2025-66471), [CVE-2026-21226](https://nvd.nist.gov/vuln/detail/CVE-2026-21226), [CVE-2026-21441](https://nvd.nist.gov/vuln/detail/CVE-2026-21441), [CVE-2026-32274](https://nvd.nist.gov/vuln/detail/CVE-2026-32274), [CVE-2026-32597](https://nvd.nist.gov/vuln/detail/CVE-2026-32597), [CVE-2026-34073](https://nvd.nist.gov/vuln/detail/CVE-2026-34073), [CVE-2026-39892](https://nvd.nist.gov/vuln/detail/CVE-2026-39892), [CVE-2026-44431](https://nvd.nist.gov/vuln/detail/CVE-2026-44431), [CVE-2026-44432](https://nvd.nist.gov/vuln/detail/CVE-2026-44432), [CVE-2026-48522](https://nvd.nist.gov/vuln/detail/CVE-2026-48522), [CVE-2026-48523](https://nvd.nist.gov/vuln/detail/CVE-2026-48523), [CVE-2026-48524](https://nvd.nist.gov/vuln/detail/CVE-2026-48524), [CVE-2026-48525](https://nvd.nist.gov/vuln/detail/CVE-2026-48525), [CVE-2026-48526](https://nvd.nist.gov/vuln/detail/CVE-2026-48526), CVE-2026-54512, CVE-2026-54513, [CVE-2026-69248](https://nvd.nist.gov/vuln/detail/CVE-2026-69248), CVE-2026-77909
