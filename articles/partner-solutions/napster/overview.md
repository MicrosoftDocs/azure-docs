# What is Napster API?

[!INCLUDE [what-is](../includes/what-is.md)]

Microsoft and [Napster](https://www.napster.com/) codeveloped this Azure Native Integration and manage it together, bringing Napster's multimodal AI agent platform into the Azure portal with unified billing, Microsoft Entra single sign-on, and full Azure resource lifecycle management.

You can find Napster API in the [Azure portal](https://portal.azure.com/#browse/napster.companionapi%2Forganizations) or get it on [Azure Marketplace](https://marketplace.microsoft.com/en-us/product/touchcastinc1655995956899.napster_companion_api).

This offering allows you to create and manage Napster API resources as an integrated Azure service. You can build persistent multimodal AI agents (Omniagents) that maintain a consistent identity, knowledge, and memory across video, voice, text, and telephony channels - and get started directly through the Azure portal.

You set up Napster API resources through a resource provider named `Napster.CompanionAPI`. You can create and manage the billing, resource creation, and authorization of Napster API resources through the Azure portal. Napster owns and runs the Software as a Service (SaaS) application, including the Napster API resources you create.

Here are the key capabilities provided by the Napster API integration:

- **Simple onboarding** - Provision Napster API as an Azure resource from the portal. No separate Napster sign-up is required.
- **Unified billing** - Pay for Napster API through Azure Marketplace as part of your monthly Azure invoice.
- **Single sign-on to Napster API** - Sign in to the Companion API Dashboard from Azure with Microsoft Entra ID. No separate credentials are required.
- **Manage all Napster API resources** from the Azure portal and track them in the **All resources** page alongside your other Azure resources.
