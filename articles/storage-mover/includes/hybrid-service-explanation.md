Azure Storage Mover supports both agent-based and agentless migration workloads. For agent-based workloads, a migration agent VM runs in your environment near the source storage. For agentless workloads, you don't need to set up a migration agent VM.

The cloud service provides migration orchestration and management for both workload types. For agent-based workloads, see the [Storage Mover agent deployment](../agent-deploy.md) and [agent registration](../agent-register.md) articles.
