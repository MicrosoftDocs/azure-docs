# Microsoft Azure operated by 21Vianet

## What is Microsoft Azure operated by 21Vianet?

Microsoft Azure operated by 21Vianet (Azure in China) is a physically separated instance of cloud services located in China. It's independently operated and transacted by Shanghai Blue Cloud Technology Co., Ltd. ("21Vianet"), a wholly owned subsidiary of Beijing 21Vianet Broadband Data Center Co., Ltd..

## Azure operations in China

### Agreement

* [Online Service Premium Agreement (OSPA) for enterprise customers](/azure/china/concepts-purchase#online-service-premium-agreement-ospa)

    * OSPA Direct – You sign OSPA with 21Vianet.
    * OSPA Indirect – You sign Indirect OSPA with 21Vianet, and sign a commercial contract with an Azure Indirect Partner.

### Pricing

For more information, see [Azure Pricing](https://www.azure.cn/pricing/).

### Service availability and roadmaps

Azure in China has a feature parity gap, but the gap is narrowing. For more information, see [Service availability and roadmaps of Azure in China](/azure/china/concepts-service-availability#service-availability-and-roadmaps).
