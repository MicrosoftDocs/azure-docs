> [!IMPORTANT]
> If you enabled a **quickstart** response plan during setup, it runs alongside your custom response plans and can cause incidents to be routed to the wrong custom agent or processed twice. To avoid conflicts, go to **Incidents** > **Triggers & response plans**, select the quickstart plan, and select **Delete**.
