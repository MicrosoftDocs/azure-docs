# Region availability and scalability

## Scaling and workload performance

Azure AI Gateway is a fully managed service that scales automatically with traffic. You don't need to manage capacity or configure scaling rules.

We recommend load testing through the gateway to check whether your application meets its latency and performance requirements as traffic changes.
