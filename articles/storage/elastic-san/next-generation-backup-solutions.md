# Backup and recovery solutions for Azure Elastic SAN Next Generation

Azure Elastic SAN Next Generation volume snapshots provide point-in-time and crash-consistent backups of your volumes. Third-party backup solutions can extend these snapshots with application-consistent protection, advanced backup policies and retention management, and recovery workflows including cross-region disaster recovery and granular file and folder recovery.

> [!IMPORTANT]
> Azure Elastic SAN Next Generation is currently in preview.
> See the [Supplemental Terms of Use for Microsoft Azure Previews](https://azure.microsoft.com/support/legal/preview-supplemental-terms/) for legal terms that apply to Azure features that are in beta, preview, or otherwise not yet released into general availability.

Commvault and Druva are Azure Elastic SAN Next Generation backup partners. Learn more about their backup solutions below:
- [Commvault](https://documentation.commvault.com/11.46/software/protect_microsoft_azure_virtual_machines.html)
- [Druva](https://www.druva.com/partners/alliances/microsoft)

## Support guidance

Before using a partner integration, confirm its availability, required product version, supported workloads, and recovery destinations with the partner. 

For issues with a third-party backup or recovery product, contact the respective partner's support team. Microsoft supports the Azure Elastic SAN service, not partner products. If troubleshooting identifies an Azure service issue, the partner can engage Microsoft support as appropriate.
