# Microsoft SQL guardrails initiative
This article describes the Policy guardrails in place to ensure Azure SQL is deployed securely.

## Initiative details

Azure Enclave assigns the SQL guardrails initiative (policy set definition ID `0fbe78a5-1722-4f1b-83a5-89c14151fa60`) to workload resource groups.

The `Effect` values in the tables show the effects supported by the policy definitions. The effective behavior of a policy assignment can vary based on Azure Enclave policy configuration and policy parameters.
The initiative references the TLS policy twice under separate reference IDs; the table lists that definition once.
