# Storage guardrails initiative
This article describes the Policy guardrails in place to ensure Azure Storage Account is deployed securely.

## Initiative details

Azure Enclave assigns the Storage guardrails initiative (policy set definition ID `ca122c06-05f6-4423-9018-ccb523168eb2`) to workload resource groups.

The `Effect` values in the tables show the effects supported by the policy definitions. The effective behavior of a policy assignment can vary based on Azure Enclave policy configuration and policy parameters.
