# Monitoring guardrails initiative
This article describes the Policy guardrails in place to ensure Azure Monitoring is deployed securely.

## Initiative details

Azure Enclave assigns the Monitoring guardrails initiative (policy set definition ID `0a9ea1cb-7925-47fc-b0fe-8bb0a8190423`) to workload resource groups.

The `Effect` values in the table show the effects that the policy definitions support. The effective behavior of a policy assignment can vary based on Azure Enclave policy configuration and policy parameters. The current initiative contains 25 policy definitions, and the diagnostic destinations listed here are Log Analytics workspaces.

## Monitoring GitHub Repository

[GitHub Repository](https://github.com/Azure/azure-policy/tree/master/built-in-policies/policyDefinitions/Monitoring)
