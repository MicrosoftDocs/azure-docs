1. On the **SKU** tab, select the Azure IoT Operations SKU for your deployment: **Standard** or **Essentials**. For more information, see [Supported SKUs](../overview-support.md#supported-skus).

   > [!NOTE]
   > You can't change the SKU after deployment. Instead, you need to create a new deployment with the desired SKU and recreate your resources like devices, assets, and dataflows on the new Azure IoT Operations instance.

1. If you select **Standard**, you can optionally choose to enable the OPC UA Connector. For **Essentials**, the OPC UA Connector isn't available.

1. Select **Configuration**.
