# Get started with configuration validation (Preview)

## Access the feature from the portal

- Go to the [Azure portal](https://portal.azure.com).

- Search for **Azure Workload Center for SAP**.

:::image type="content" source="media/configuration-validation/azure-portal-search-workload-center-sap.png" lightbox="media/configuration-validation/azure-portal-search-workload-center-sap.png" alt-text="Screenshot of Azure Portal search results for azure workload center for SAP showing matching services.":::

- You see the overview page.

:::image type="content" source="media/configuration-validation/workloads-hub-overview-page.png" lightbox="media/configuration-validation/workloads-hub-overview-page.png" alt-text="Screenshot of Azure Workloads Hub overview with Workload Virtual Instance, Configuration checks, and Workload health panels.":::

- Expand the **Workload Resources** section and select the **Workload Virtual Instances** option to open the relevant WVI.

:::image type="content" source="media/configuration-validation/workload-virtual-instances-list.png" lightbox="media/configuration-validation/workload-virtual-instances-list.png" alt-text="Screenshot of Workload Virtual Instances list for Caldova, showing SAP system names, state, and architecture type.":::

- Check out the different components of virtual instance.

:::image type="content" source="media/configuration-validation/azure-sap-workload-components-list.png" lightbox="media/configuration-validation/azure-sap-workload-components-list.png" alt-text="Screenshot of Workload components page listing SAP servers with state, type, and location details.":::
