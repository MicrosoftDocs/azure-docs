# Azure Workload Center for SAP overview
## Azure Center for SAP solutions is now Azure Workload Center for SAP

Azure Workload Center for SAP provides a centralized Azure experience for managing and operating SAP workloads on Azure.

Azure Workload Center brings together SAP-specific management experiences and provides two ways to represent and manage SAP systems in Azure: **Virtual Instance for SAP solutions** and **Workload Virtual Instance (Preview)**.

This article helps you understand the available experiences and choose the right one for your SAP environment.

Azure Center for SAP solutions is now **Azure Workload Center for SAP**.

As part of this evolution, the existing Azure Center for SAP solutions experience continues as **Virtual Instance for SAP solutions (VIS)** within Azure Workload Center for SAP.

Azure Workload Center for SAP also introduces the **Workload Virtual Instance (WVI)** experience in limited preview. WVI provides workload context that enables newer operational capabilities for SAP systems on Azure.

## Choose the right experience

Azure Workload Center for SAP provides two experiences for SAP systems. Choose the experience based on the type of environment you want to manage.

| **Experience**                               | **Availability**    | **Recommended use**             |
|----------------------------------------------|---------------------|---------------------------------|
| **Virtual Instance for SAP solutions (VIS)** | Generally available | **Production environments**     |
| **Workload Virtual Instance (WVI)**          | Limited Preview             | **Non-production environments** |

### Virtual Instance for SAP solutions

Use **Virtual Instance for SAP solutions (VIS)** for production SAP systems.

VIS is the existing generally available experience previously provided through Azure Center for SAP solutions.

To learn about VIS capabilities, supported scenarios, and how to register and manage SAP systems, see **Virtual Instance for SAP solutions overview**.

### Workload Virtual Instance (Preview)

Use **Workload Virtual Instance (WVI)** to explore the new Azure Workload Center for SAP experience for non-production SAP systems during preview.

A WVI represents an SAP system, its workload components, and the Azure resources that support them. This workload context enables experiences such as configuration validation, workload health observability, workload-aware recommendations, and AI-assisted investigation with Azure Copilot Run SAP agent.

During preview, use WVI for **non-production environments**.

To learn about WVI capabilities, supported configurations, and how the workload representation works, see **Workload Virtual Instance overview**.

> [!IMPORTANT]
> The Workload Virtual Instance is currently in preview.

The Workload Virtual Instance (WVI) experience is currently available in preview for non-production SAP environments.

If your organization operates mission-critical SAP systems on Azure and wants to help shape the next generation of workload-level operations, [register your interest in the Azure Workload Center for SAP preview](https://aka.ms/workloadcenter/SAP-signup).

After you submit the form, the Azure Workload Center for SAP product team will review your request and provide access to the preview for eligible customers.
